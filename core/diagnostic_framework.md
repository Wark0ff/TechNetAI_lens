# Диагностическая рамка проекта/технологии

Пошаговая карта для полной диагностики. Каждый шаг даёт вход для схемы
`schemas/analysis_output.schema.json`.

## Шаг 1. Паспорт объекта

- Что это: изделие, процесс, проект, платформа, стандарт, политика.
- Отрасль/рынок НТИ и назначение.
- Период, стадия (идея / НИОКР / пилот / серия / эксплуатация).
- Базовая линия «как есть».

## Шаг 2. Технологический стек

Отметь применяемые ППТ по четырём группам:

- Вычислительные и модельные: CAD, CAE, HPC, PLM, PDM, CAM, CAAM, MBSE,
  цифровые двойники.
- Производственные: аддитивные, ЧПУ, гибрид, робототехника, сенсорика.
- Данные и интеллект: IIoT, Big Data, MES, ERP, ИИ, платформы.
- Материалы: сплавы, полимеры, композиты, метаматериалы.

Для ключевой технологии укажи TRL с обоснованием.

## Шаг 3. Цифровая связность

- Есть ли «цифровая нить» (сквозные данные по жизненному циклу)?
- Уровень цифрового двойника: изделие / процесс / производственная система.
- Степень валидации моделей по натурным данным.

## Шаг 4. Профиль пяти измерений

Оцени каждое (см. `data/project_diagnostic.json`): проектирование; ЖЦ и данные;
производство; данные и интеллект; суверенитет и материалы. Для каждого —
направление изменения, доказательство, неопределённость, недостающие данные.

## Шаг 5. Барьеры зрелости

Отметь наличие типовых разрывов: проектирование, данные, испытания,
производство, интеграция, материалы, суверенитет, кадры, масштабирование.

## Шаг 6. Уровень зрелости системы

Назови доминирующий уровень F0–F5, диапазон и противоречащие признаки. Укажи
условия перехода на уровень выше.

## Шаг 7. Эффекты и метрики

Для каждого заявленного эффекта: метрика, базовая линия, механизм, источник,
альтернативные объяснения, уверенность.

## Шаг 8. Суверенитет и владение

- Доля отечественного ПО и оборудования.
- Права на данные, код, модели, патенты, стандарты.
- Зависимость от импортного сервиса и запчастей.
- Состояние инженерных школ и кадров.

## Шаг 9. Альтернативы и стресс-тест

Проверь неинженерные причины результата и проведи стресс-тест по протоколу
рассуждения (TRL, валидация, стоимость владения, кибербезопасность, зависимость,
кадры, масштабирование, обратимость).

## Шаг 10. Варианты и рекомендации

Сформируй варианты по трём рычагам, компромиссы, условные рекомендации и точки
пересмотра. Вынеси неизвестные данные и общую уверенность.
