# Как пользоваться — просто

## Вариант 1. В обычном чате (самый быстрый)

1. Откройте нейросеть (ChatGPT, GigaChat, YandexGPT, Claude и т.п.).
2. Прикрепите файл **`01_SINGLE_FILE_LENS.md`** (или вставьте его текст в чат).
3. Скопируйте и отправьте текст из **`02_SESSION_BOOTSTRAP.txt`**.
4. Напишите свою задачу. Например:
   - «Проанализируй наш проект цифрового двойника … по этой оптике».
   - «Оцени цифровую зрелость участка … и дай уровень F0–F5».
   - «Сравни два решения … по суверенитету и TRL».

Готово. Модель ответит по единому формату (вывод → факты → механизм → уровень
зрелости → риски → рекомендации).

## Вариант 2. Как бот/ассистент с базой знаний

1. В поле «системная инструкция» вставьте **`prompts/system_prompt_full_ru.txt`**.
2. В «базу знаний» загрузите папки **`core/`** и **`data/`**.
3. Чтобы бот отвечал по отчётам — положите PDF в **`sources/`** (см. ниже) и
   загрузите их в базу знаний.

## Вариант 3. Навигатор по отчётам

Спросите, например: «Что говорят отчёты Технет про новые материалы?»
Модель найдёт нужный отчёт в `data/reports_catalog.json` и:
- если текст отчёта разобран (4 отчёта 2026 г.) — приведёт тезисы и ссылку;
- если нет — назовёт файл и скажет, что для точных цитат его нужно разобрать.

## Где взять сами отчёты (PDF)

Отчёты лежат в репозитории через **Git LFS**. Чтобы получить их при клонировании,
поставь [git-lfs](https://git-lfs.com) один раз:

```bash
git lfs install
git clone <ссылка-на-репозиторий>
```

PDF подтянутся сами в папку `sources/`. Если LFS недоступен — есть резервная
докачка с сайта: `powershell -ExecutionPolicy Bypass -File scripts/fetch_sources.ps1`.

## Что важно помнить

- Это **аналитическая рамка**, а не официальный стандарт.
- Оптика намеренно строгая: не хвалит проект за один ярлык «у нас цифровой
  двойник» — просит цифры, базовую линию и уровень готовности (TRL).
- Числа из отчётов — на дату отчёта; перед внешним использованием проверяйте.
