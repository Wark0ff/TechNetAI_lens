# Машиночитаемая оптика «Технет НТИ» (TechNet AI Lens)

Пакет превращает материалы Инфраструктурного центра «Технет» СПбПУ (НТИ) в
аналитическую оптику для нейросети. Делает две вещи:

1. **Диагностика зрелости** — оценивает промышленный/технологический проект по
   передовым производственным технологиям, цифровой зрелости, типу Фабрики
   Будущего (F0–F5) и технологическому суверенитету.
2. **Навигатор по отчётам** — отвечает на вопросы и цитирует отчёты ИЦ «Технет»
   2019–2026 из базы знаний.

👉 **Как пользоваться — см. [КАК_ПОЛЬЗОВАТЬСЯ.md](КАК_ПОЛЬЗОВАТЬСЯ.md)** (просто и по шагам).

## Структура

| Папка/файл | Что внутри |
|---|---|
| `01_SINGLE_FILE_LENS.md` | всё-в-одном: загрузить в чат — и оптика работает |
| `prompts/` | системные промпты для бота/агента (полный + компактные ru/en) |
| `core/` | ядро знаний, протоколы доказательств и рассуждений, диагностика |
| `data/` | шкала зрелости, словарь, онтология, каталог и индекс отчётов |
| `schemas/` | JSON-схемы структурированного ответа |
| `eval/` | чек-лист приёмки + тест-кейсы |
| `examples/` | разобранный пример анализа |
| `sources/` | тексты отчётов (PDF) — **в git не хранятся**, см. ниже |

## Отчёты (папка sources/)

Тексты отчётов (~780 МБ, 86 файлов) **намеренно исключены из git** (`.gitignore`).
Они восстанавливаются одной командой из `data/sources_inventory.json`:

```bash
# Windows
powershell -ExecutionPolicy Bypass -File scripts/fetch_sources.ps1
# Linux/Mac/Git Bash
bash scripts/fetch_sources.sh
```

- `data/reports_catalog.json` — каталог всех 86 отчётов (метаданные, темы, годы).
- `data/reports_index.json` — 4 отчёта 2026 г. с разобранным текстом (тезисы + точные ссылки для цитирования).
- `data/sources_inventory.json` — имя файла → исходный URL → размер.

Если нужно, чтобы PDF **хранились в git**, — уберите строки `sources/*.pdf` из
`.gitignore` (учтите: репозиторий станет ~780 МБ, отдельные файлы до 40 МБ; для
GitHub лучше подключить Git LFS).

Аналитическая оптика на базе материалов ИЦ «Технет» СПбПУ. Не официальный
